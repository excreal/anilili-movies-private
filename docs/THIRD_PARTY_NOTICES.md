# Bundled media tooling

Saved videos open in the system default external player. No LibVLC runtime is
bundled with the app.

The ARM64 FFmpeg executable used for cached HLS export is distributed under LGPL
2.1. Its bundled license is in `app/src/main/assets/licenses/FFmpeg-LGPL-2.1.txt`.
Source and binary provenance are documented in the README's FFmpeg section.
